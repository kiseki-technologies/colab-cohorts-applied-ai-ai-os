# Weekly feedback themes

**Cadence:** weekly, Monday morning
**Needs:** any feedback source — support tickets, a Slack channel, review exports, a form

---

## The prompt

```
Every [Monday] at [07:00], read [SOURCE] from the last [7] days.

Group into themes. For each theme:
- number of mentions
- verbatim quotes, attributed to segment where you can tell
- whether this theme appeared in last week's file — mark NEW if not

Do not merge themes that sound similar but have different underlying causes.
Where a theme rests on a single mention, list it under SIGNALS rather than THEMES.

Write to feedback-themes/[DATE].md. If volume was too low to draw themes, say so — don't
manufacture structure from four comments.
```

---

## What good looks like

The NEW flag is what makes this worth reading weekly rather than monthly. Established themes
you already know; a new one appearing is information.

The SIGNALS section stops single loud customers becoming "a theme".

## Tuning

If everything comes back as one giant theme, your source is too narrow or your window too
short. If nothing repeats, widen to 30 days and run monthly instead.
